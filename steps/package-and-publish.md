# 07 发布包、上传与发布 / Package and publish

## 目标

把正式成片和平台文案整理成一个可追踪的发布任务，并把上传与真实提交分成两个状态。

## 操作

1. 只从 `final_ready` 成片生成标题、简介、话题/标签、封面和平台清单。
2. 先执行 `Prepare`：登录检查、上传、填写表单并停在最终提交前。
3. 只有当前请求明确授权真实提交，且清单已批准，才执行 `Publish`；公开 B 站投稿还要额外的公开确认开关。
4. 每个平台一次持久会话只上传一次；遇到超时、选择器失败、重定向或结果不明时保留证据并停止。
5. 从作品管理或平台页面核验 URL、ID、可见性和时间，不能用重定向或进程退出推断成功。

## 输出

平台清单、上传证据、发布登记或明确的未知状态。

## 闸门

账号授权、当前发布许可、清单批准、正式成片和 QA 都有效。不同平台的许可不能互相继承。
