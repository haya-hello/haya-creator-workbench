# Workbench routing

Users may describe the desired outcome directly; these names are optional shortcuts.

| Natural request | Internal route | Primary reference | Boundary |
| --- | --- | --- | --- |
| Find an angle, rewrite a draft, score, predict, or review results | Content workbench | `references/content-workflow.md` | Does not render video |
| Edit ordered talking-head footage or revise captions/audio | Editing workbench | `references/editing-workflow.md` | Does not infer platform authorization |
| Upload, schedule, publish, or verify a platform result | Publishing workbench | `references/publishing-workflow.md` | Real submission needs current explicit approval |
| Install on a new machine or initialize a workspace | Setup workbench | `references/installation.md` | Does not create platform sessions |
| Resume an interrupted item | Recovery workbench | `references/state-contract.md` | Trust state files over chat history |
